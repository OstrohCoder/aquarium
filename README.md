# Віртуальний акваріум

Інтерактивний 3D-акваріум, створений за допомогою **Three.js** та **Vite**. Проєкт дозволяє спостерігати за підводним світом, взаємодіяти з рибами, годувати їх, змінювати декорації, рослинність, освітлення та параметри води.

Окрему увагу приділено реалістичному відображенню води, скла, освітлення, тіней, анімації та поведінці мешканців.

## Основні можливості

- **3D-сцена:** акваріум зі скляними стінками, ґрунтом, водою та декораціями.
- **Мешканці:** декілька видів риб із власними моделями, характеристиками та поведінкою.
- **Анімація:** плавання риб, рух плавців, коливання рослин, хвилі на поверхні води та бульбашки.
- **Взаємодія:** годування риб кліком миші, реакція риб на курсор, перегляд інформації про окремих мешканців.
- **Налаштування середовища:** зміна рослинності, декорацій, освітлення та кольору води.
- **Вільна камера:** можливість оглядати акваріум під різними кутами.
- **Екосистема:** контроль чистоти води, температури, корму та здоров'я риб.
- **Графічні ефекти:** шейдери води, каустики, освітлення та тіні.

## Встановлення та запуск

Клонуйте репозиторій:

```bash
git clone https://github.com/OstrohCoder/aquarium
cd aquarium
```

Встановіть залежності:

```bash
npm install
```

Запустіть локальний сервер:

```bash
npm run dev
```

Для створення production-збірки:

```bash
npm run build
```

## Керування

- **Миша:** огляд сцени та взаємодія з акваріумом.
- **Клік по воді:** додавання корму.
- **Рух курсора над рибами:** реакція мешканців на наближення.
- **Клік по рибі:** перегляд її характеристик.
- **Панель GUI:** зміна параметрів акваріума та його мешканців.
- **Вільна камера:** обертання та переміщення навколо сцени.

## Структура проєкту

- `public/` — статичні ресурси, текстури та 3D-моделі.
- `src/core/` — основні компоненти рендерингу, камери, завантаження ресурсів та введення.
- `src/world/` — акваріум, вода, освітлення, ґрунт, рослинність і декорації.
- `src/fish/` — моделі риб, їхні характеристики, анімація та поведінка.
- `src/physics/` — фізична симуляція корму та інших об'єктів.
- `src/ecosystem/` — логіка стану екосистеми.
- `src/shaders/` — вершинні та фрагментні GLSL-шейдери.
- `src/ui/` — графічний інтерфейс та інформаційна панель.

## Технічні особливості

**Three.js** використовується для створення та відображення тривимірної сцени.

**GLSL-шейдери** забезпечують анімацію поверхні води, каустики та деформацію геометрії риб і рослин.

**Процедурна генерація** використовується для створення моделей риб, частини рослинності та декорацій.

**cannon-es** використовується для фізичної взаємодії корму з навколишнім середовищем.

**lil-gui** забезпечує інтерактивне налаштування параметрів сцени.
